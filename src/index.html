Quick Start

01

Start the hub

Launch the local proxy. NVIDIA, OpenCode and Kilo endpoints become available.

02

Pick a provider URL

Use /nvidia/v1, /opencode/v1 or /kilo/v1 — each has its own key pool (Kilo works without a key).

03

Send any key

Clients can send any Bearer token — the hub injects rotating keys from that provider’s pool.

curl http://127.0.0.1:59714/opencode/v1/models -H "Authorization: Bearer any-key"

Settings

Appearance, anonymity, server bind, and upstream base URLs

Theme

Anonymous mode

Each request gets a new persona: TLS/HTTP2 fingerprint, browser headers, languages, and any device/session fields (device id, machine id, MAC-like headers, install id, fingerprints, cookies). Real MAC/serial never leave your PC over HTTPS — we block any client that tries to send them. IP is unchanged (use Proxy for that).
